# CV Builder

A responsive CV builder built with React that allows users to enter their personal information, education, and work experience to generate a structured CV.

## Live Demo
- [View Live Project](https://cv-application-project-xi.vercel.app/)

## Features
- Add personal information, including name, email, and phone number.
- Enter educational background and qualifications.
- Add work experience, including company, role, responsibilities, and employment dates.
- Generate a CV using the provided information.
- Edit information before generating the CV.
- Responsive user interface.

## Skills Demonstrated
- **State Management (`useState`)**: Handling dynamic data for the user's personal info, education, and work experience.
- **Props**: Passing state and handler functions between parent and child components (e.g., passing form data to the CV preview).
- **Controlled Components**: Managing form inputs directly through React state to keep the UI in sync.
- **Component Architecture**: Breaking down the UI into modular, reusable components for forms and previews.
- **Event Handling**: Managing user interactions like input changes, form submissions, and toggling edit modes.

## Getting Started

### Prerequisites
- Node.js
- npm

### Installation
1. Clone the repository: `git clone https://github.com/ramicoder/cv-application-project.git`
2. Navigate to the project directory: `cd main`
3. Install dependencies: `npm install`
4. Start the development server: `npm run dev`
5. Open the local URL provided by Vite in your browser.

## Building for Production
Run the following command to create a production build:

```bash
npm run build
```
The generated production files will be available in the `dist` directory.

## Deployment
Deployed using Vercel, with automatic deployments connected to GitHub.
